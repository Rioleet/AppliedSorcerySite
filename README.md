# Applied Shamanism website

This is the public website for Applied Shamanism. It contains only the static site and approved Steam media; the Unity game project is separate.

## Edit the site

Sign in to GitHub with the Rioleet account, open this repository, select `index.html` or `press.html`, click the pencil icon, and commit the change to `main`. CSS is in `styles.css` and `cozy.css`; screenshots are in `media/`. Cloudflare Pages republishes changes after a successful commit to `main`.

The press page links to the shared Google Drive folder for the future full press-kit archive. To replace that folder, edit the link in `press.html`. Press inquiries go to vvarlamovkz@gmail.com.

## Publishing

Cloudflare Pages is connected to this repository with production branch `main`. The primary site URL is `https://appliedshamanism.pages.dev/`. The GitHub Pages URL `https://rioleet.github.io/AppliedSorcerySite/` remains available.
